# 🏗️ Crestpoint — Construction Experts in Uganda

Crestpoint is a forward-thinking construction firm delivering bold, reliable infrastructure across Uganda. This website showcases our services, projects, and team, built with modular HTML, CSS, and JavaScript for clarity and scalability.

## 🚀 Live Demo
[Visit Crestpoint Website](https://saldee.github.io/Crestpoint/index.html)

## 🧰 Tech Stack
- **HTML5** — Semantic structure for modular sections
- **CSS3** — Responsive, visually dominant layout
- **JavaScript** — Dynamic content, form handling, and interactivity

## 📁 Project Structure

| Folder/File         | Purpose                                      |
|---------------------|----------------------------------------------|
| `index.html`        | Homepage with hero section and intro         |
| `services.html`     | Detailed service offerings                   |
| `projects.html`     | Portfolio of completed and ongoing projects  |
| `contact.html`      | Contact form and company info                |
| `about.html`        | Mission, values, and team overview           |
| `css/`              | Modular stylesheets                          |
| `images/`           | Visual assets                                |
| `main.js`           | Core interactivity                           |
| `populate.js`       | Dynamic content injection                    |
